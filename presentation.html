1. Core Networking & Add-ons

  • Cilium CNI: eBPF-based networking, routing, and high-performance policies.
  • External Secrets Operator: Syncs secrets from GCP Secret Manager directly to K8s.
  • Headlamp Dashboard: Real-time K8s visualization.

2. Data & State

  • CloudNativePG: Enterprise-grade PostgreSQL operator with automated backups/failover.
  • Redis & RabbitMQ: Scalable StatefulSets for message brokering and caching.

3. Application Layer

  • Go Proxy: High-performance API gateway with CoinGecko integrations.
  • History Worker: Asynchronous market data processing.
  • UI (SPA): Next-generation web interface.

Zero-Trust & Edge Security

Identity & Access

  • Cloudflare Access: SSO identity verification before hitting the Cloudflared tunnel.
  • Tailscale Operator: Secure mesh VPN ingress directly to K8s services.

Micro-Segmentation

Strict CiliumNetworkPolicy rules:

  • Default Deny-All: No unauthorized lateral movement.
  • eBPF Filtering: Extremely fast network dropping at the kernel level.
  • Identity-based: Matches host and pod identities directly.
