Core Infrastructure

A robust, highly available foundation.

1. Compute

  • K3s on GCP: Lightweight, highly available Kubernetes.
  • Zero Public IPs: Exclusively accessed via Google Identity-Aware Proxy (IAP) SSH tunnels.

2. Data & State

  • CloudNativePG: Enterprise-grade PostgreSQL operator.
  • Redis & RabbitMQ: Scalable StatefulSets for message brokering and caching.

3. Application Layer

  • Go Proxy: High-performance API gateway.
  • History Worker: Asynchronous market data processing.
  • UI (SPA): Next-generation web interface.

Zero-Trust & Edge Security

Micro-Segmentation

Strict NetworkPolicy rules across namespaces:

  • Default Deny-All: No lateral movement.
  • Explicit Allow: e.g., Proxy can talk to Redis, but not directly to DB.

Cloudflare Tunnels

  • Inbound traffic tunneled securely via cloudflared.
  • No exposed ports on nodes.
  • DDoS protection at the edge.

Future Roadmap

  • Observability: Deploying Prometheus, Grafana, and Loki via GitOps for metrics and distributed tracing.
