Executive Summary

The Challenge

  • Deployment bottlenecks & manual scripts
  • Implicit trust networks (Security risks)
  • Configuration Drift (Prod != Docs)

The Solution

  • 100% Declarative K3s Architecture
  • Zero-Trust Network Micro-segmentation
  • Automated GitOps Reconciliation (ArgoCD)

Architectural Paradigm Shift

Legacy (Imperative) Modern (GitOps & Cloud-Native)
Manual Bash Scripts Ansible Bootstrapping + Terraform
Manual Secret Management External Secrets Operator (GCP Secret Manager)
Terminal/kubectl Updates Git as Single Source of Truth (ArgoCD)
Flannel & iptables Cilium eBPF CNI & Network Policies

Core Infrastructure

  • Networking: Cilium CNI (eBPF policies), External Secrets (GCP Sync), and Headlamp (Visualization).
  • Data & State: CloudNativePG (PostgreSQL operator), Redis, and RabbitMQ (Stateful message brokering).
  • Application Layer: Go Proxy (API Gateway), History Worker (Python background processing), and the Next-Gen UI (SPA).

Unified Helm Architecture

The Umbrella Chart

  • Consolidated Deployment: The entire platform is deployed as a single Helm release (`coin-ops`).
  • Sub-Charts: Infrastructure dependencies (RabbitMQ, Redis) are cleanly managed as standard Helm sub-charts.

Dynamic Templating

  • DRY Principles: Reusable `_helpers.tpl` functions reduce YAML duplication.
  • Environment Agnostic: A single, unified `values.yaml` acts as the control plane for scaling, enabling/disabling features, and configuring routing.

Zero-Trust & Edge Security

Identity & Access

  • Cloudflare Access: SSO identity verification before hitting the Cloudflared tunnel.
  • Tailscale Operator: Secure mesh VPN ingress directly to K8s services.

Micro-Segmentation

Strict CiliumNetworkPolicy rules:

  • Default Deny-All: No unauthorized lateral movement.
  • eBPF Filtering: Extremely fast network dropping at the kernel level.
  • Identity-based: Matches host and pod identities directly.

The GitOps Workflow

Source of Truth

  • GitHub Repository: Holds the entire desired state of the infrastructure.
  • Developer Action: Standard `git push` initiates all deployments.

Reconciliation

  • ArgoCD Controller: Continuously polls Git and compares it to live state.
  • Self-Healing: Any manual cluster changes are instantly reverted.
